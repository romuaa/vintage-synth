**Unsigned first release.** These builds are not code-signed and there are no installers: unpack the zip for your platform and follow its `INSTALL.txt` (it explains the one-time step that the unsigned plugin needs on macOS and Windows).

**Experimental:** the Windows ARM64 and Linux ARM64 parts of the Windows and Linux bundles are built and unit-tested only. They have not been run through the plugin validator and are not performance-tuned. macOS (universal), Windows x64 and Linux x86_64 are the checked builds.

The complete source for each zip is named in its `SOURCE.txt`.
